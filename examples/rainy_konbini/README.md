# 雨夜のコンビニ — Rainy Night Konbini

以 three.js（WebGLRenderer, r186）即時渲染的 3D 互動小遊戲：雨夜裡，長髮少女撐著透明傘，跑向街角亮著暖光的日本便利商店，完成「おつかい（跑腿）」任務後再冒雨回家。

全部內容皆為程式生成（幾何、貼圖、角色、音效），不載入任何外部模型、貼圖或音檔。

## 執行

```bash
# 在 repo 根目錄
npx http-server -c-1 .
# 瀏覽 http://localhost:8080/examples/rainy_konbini/
```

URL 參數：`?q=low|medium|high` 畫質、`?debug` 顯示 FPS。

## 操作

| 按鍵 | 動作 |
|---|---|
| WASD / 方向鍵 | 移動（以鏡頭為基準） |
| Shift | 衝刺 |
| Z | 走路 / 慢跑切換 |
| E / Enter | 互動（拿商品、ATM、櫃台結帳） |
| Q | 開 / 收傘 |
| 滑鼠拖曳、滾輪 | 旋轉鏡頭、遠近 |
| P | 寫真模式（隱藏 UI、自由鏡頭） |
| H / M | 操作說明 / 靜音 |

手機：左半螢幕虛擬搖桿、右半拖曳轉鏡頭，右下角有互動／衝刺／傘／拍照按鈕。

## 任務流程

1. 從對面人行道出發，穿過斑馬線走進「ツキマート」。
2. 收集購物清單：鮭おにぎり、冷たい緑茶、とろけるプリン。
3. 錢不夠 → 用 ATM 領錢（可選金額、查詢餘額）。
4. 櫃台結帳（可加購肉まん）。
5. 冒雨回到對面人行道 → 結算（時間、淋濕度、評價 S/A/B/C）。

## 畫面與技術重點

- **積水倒影**：`Reflector` 平面反射，自訂 shader 合成水窪遮罩（fbm）、程式化雨滴漣漪、腳步／滴水動態漣漪、濕柏油的垂直拖影反射與 Fresnel。
- **雨絲**：GPU instanced 雨線，世界座標穩定並隨鏡頭環繞；依附近光源（店面暖光、自販機、路燈、計程車頭燈）上色；屋簷／室內／傘下自動遮蔽。地面水花、屋簷滴水簾、傘骨滴水、腳步濺水、輪胎水霧。
- **冷暖對比**：室內暖白光＋RectAreaLight 溢出到濕地面，戶外冷藍環境光與 LED 路燈；體積光錐；夜空雲層受城市光汙染照亮。
- **角色**：程式建模長髮少女，依移動距離驅動的程序化步態（idle / walk / jog / sprint 連續混合），Verlet 長髮模擬、裙擺擺動、透明傘開合與彈簧擺動。
- **場景細節**：日文招牌與海報、貨架商品、冷藏櫃、ATM、多功能事務機、櫃台、自動門、自販機、ママチャリ、電線桿、斑馬線、對街店家等。
- **後製**：MSAA HDR → 防溢出 clamp → UnrealBloom → 調色（青影琥珀光）、色差、暗角、底片顆粒、鏡頭雨滴 → OutputPass（ACES）。
- **音效**：WebAudio 程序化雨聲（室內低通悶音）、傘面雨滴聲、腳步、自動門鈴、店內音樂盒、車輛濺水聲。
- 動態解析度：FPS 持續偏低時自動降低像素比。
